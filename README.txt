# SmartDorm Energy System

Prototype web app untuk konsep "Smart Dormitory Energy System".

## Cara menjalankan di VS Code
1. Ekstrak folder ini.
2. Buka folder di VS Code.
3. Buka `index.html`.
4. Jalankan dengan Live Server jika punya extension Live Server, atau buka langsung di browser.

## Teknologi
- HTML
- CSS
- JavaScript
- Tidak menggunakan Python.

## Fitur interaktif
- Tombol ON/OFF lampu, AC, kipas, dan charger.
- Tombol "Matikan semua".
- Mode hemat energi.
- Dropdown periode monitoring.
- Navigasi Beranda, Monitoring, Notifikasi, Profil.
- Simulasi status penghuni kamar.
- Toast/notifikasi interaktif.
